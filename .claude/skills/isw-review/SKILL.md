`<YY.MM>` = папка сессии (напр. `26.10`): все карты сессии, весь её диапазон дат.

# Проверка папок с пользователем

> С пользователем — только на русском: ответы, вопросы, кнопки, окошко итога, отчёты.

**Правила пользователя:**
- **Папка, из которой сделано видео, получает «+» в начале имени** (`+Kherson_26.01.02-26.10.13`); `maps.py video`
  ставит его сам. Видео — без «+». В командах папку можно называть без «+» и без дат. После `split` «+» снимается.
- Склеивать (`merge`) — только если совпадают И место, И масштаб (ISW лишь переименовал карту). Разное место
  или масштаб — НИКОГДА не склеивать, даже при одинаковом названии.
- Пользователь может разбирать папки сам и просто сказать «папка X — всё ок, делай». Это значит: он уже САМ удалил
  из папки ненужные/битые карты. Не спрашивать, не восстанавливать. Сразу: `maps.py ranges` (даты в имени могли
  измениться) → `normalize <Папка>` → `video <Папка>`. Если normalize ругается на h/w — сказать, какие файлы.
- Имя папки: `[+]<Имя по шаблону>[_old]_<первый>-<последний>` (шаблон и таблица — CLAUDE.md, `scripts/names.json`);
  в командах можно без «+» и без дат.
- Одно название направления ≠ одна карта: масштаб/область могут отличаться. Сравнивать масштаб по положению
  одних и тех же городов и рек относительно рамки и по линейке масштаба, а не по похожести «на глаз».
- **Папка нужна, только если в ней ≥ 3 карт и от первой до последней даты ≥ 15 дней** (`maps.py prune` убирает
  остальные в `_removed`; запускать после обрезки и после любых правок). Видео — кадр раз в неделю, дни между
  недельными кадрами малоинтересны.

Делается после обрезки, до уменьшения. Причина: ISW иногда меняет саму карту (масштаб, область),
оставляя то же название направления.

1. Для каждой папки **по отдельности**:
   - `python scripts/maps.py check <YY.MM>` — посмотреть h/w;
   - самому посмотреть первую, последнюю и все карты рядом с точкой, где меняется размер/соотношение;
   - показать пользователю: число карт, диапазон дат, пропуски, подозрительные места (с картинками через SendUserFile);
   - спросить: «Всё ли в папке правильно и везде ли одна и та же карта?» — ждать ответа, не переходить к следующей папке.
2. Если пользователь просит разделить с даты:
   `python scripts/maps.py split <YY.MM> <Папка> <yy.mm.dd>` → старые дни в `<Папка>_old_<первый>-<последний>`,
   новые в `<Папка>_<первый>-<последний>` (имена с диапазоном дат обновляются сами).
3. Если просит убрать дни:
   `python scripts/maps.py remove <YY.MM> <Папка> <yy.mm.dd> ...` → файлы уходят в `_removed/<Направление>/` (без диапазона и `_old`; одинаковые имена → `_dup`).
4. Если одно направление лежит в нескольких папках (ISW переименовал карту) — склеить:
   `python scripts/maps.py merge <YY.MM> <Цель> <Папка> [<Папка> …]` → карты и их оригиналы в `_raw` переезжают
   в папку-цель, пути в манифестах обновляются. Совпадение дат — ошибка, ничего не переносится.
5. Перед вопросом по папке: `python scripts/maps.py sheet <YY.MM> <Папка>` — лист миниатюр в `_review/<Папка>.jpg`
   и список подозрительных дней (резкая смена картинки / другое h/w). Общего отчёта нет — `sheet` по каждой папке.
   Похожие по названию папки показывать вместе (одна полоса карт), чтобы пользователь сразу решил про склейку.
6. Записать решения в журнал `PLAN.md` (раздел «Решения по папкам»).
