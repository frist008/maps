# Заливка на YouTube

> С пользователем — только на русском: ответы, вопросы, кнопки, окошко итога, отчёты.

Делается **после последнего видео сессии** (все папки с «+»), автоматически, но таблицу названий
перед заливкой показать пользователю.

## Канал
- «Карты: Россия Против Украины с 2022года», id `UCTtVqFb4dCyz8m0tJk3Du9Q`.
- Studio: https://studio.youtube.com/channel/UCTtVqFb4dCyz8m0tJk3Du9Q/videos/short
- Работать в Chrome пользователя (Claude in Chrome), там аккаунт уже залогинен. Если открыт другой канал —
  переключиться на этот через аватар → «Сменить аккаунт/канал». Пароли не вводить.

## Название
`<Направление по-русски> — <Сезоны> <Год>, Карта: Россия против Украины`
- Примеры с канала: `Херсон — Осень, Зима 2025, Карта: Россия против Украины`,
  `Купянск север, Велико-Бурлуковское направление — Осень, Зима 2025, …`.
- Русские имена направлений — как в прошлых шортсах того же направления (таблица — `names_ru.json`
  рядом со скилом, дополнять).

- **Лимит YouTube — 100 символов.** Длиннее — сокращать имя направления (например, без слова «направление»):
  `Купянск север, Велико-Бурлуковское — …`.

## Метаданные (как у прошлых шортсов)
- Плейлист: **Россия против Украины**.
- Аудитория: **Нет, это видео не для детей**. Возраст: подходит для младше 18.
- **Прямая реклама: «Нет, в видео нет прямой рекламы»** и **Использование ИИ: «Нет»** — оба переключателя
  выбрать явно (импорт сведений их НЕ ставит; в 26.10 у всех 37 остались пустыми). `ytFill` ставит их сам, если
  они есть в окне загрузки (в ответе `radios`: «нет в окне» — значит нет); иначе/для проверки — `ytFix({radios: [...]})`.
- Остальное — как у прошлых шортсов (сверено в 26.10): плейлист, язык видео «Нет», причина без субтитров
  «не транслировался по ТВ США», ремиксы «видео и аудио», эпизоды/места/понятия включены, «Опубликовать в фиде
  подписок» включено, модерация отключена, комментировать могут «Все», «Сначала интересные», счётчик «Нравится».
- Теги: `Россия, Украина, война, war, Russia, Ukraine, <Город по-русски>, <City in English>, карта, map`.
- Язык названия и описания: Русский. Категория: **Новости и политика**. Лицензия стандартная, встраивание разрешено.
- Комментарии включены.
- **Видео по теме (ссылка под шортсом) — обязательно.** Каждый шортс ссылается на предыдущий по порядку
  публикации: №N → №N−1 (более новый → на тот, что старше). №1 — на последний шортс прошлой сессии.
  Импорт сведений это поле НЕ копирует — ставить отдельно (шаг 6).
- **Доступ: «Ограниченный доступ» (Private)** — публикует пользователь сам.
- **Описание пишет пользователь.** Можно только скопировать описание прошлого шортса, если карта та же
  (то же направление/название). Новая карта — описание оставить пустым, не придумывать.

## Чек-лист каждого нового шортса (итог сессии 26.10 — делать ВСЁ, ничего не пропускать)
1. Название по шаблону (≤100 символов, «Сумы» с одной «м»); описание — копия прошлого шортса той же карты,
   для новой карты пусто (пишет пользователь; назвать ему номера с пустым описанием).
2. Плейлист «Россия против Украины»; «не для детей»; возраст — «подходит для младше 18».
3. **Прямая реклама — «Нет, в видео нет прямой рекламы»; Использование ИИ — «Нет»** (явно, импорт не ставит).
4. Теги по шаблону; язык названия/описания — Русский; язык видео — «Нет»; категория «Новости и политика».
5. **Видео по теме = предыдущий шортс** (№N → №N−1, №1 → последний шортс прошлой сессии). Ставить после
   заливки всех, по порядку, `ytFix({rel})`.
6. Доступ «Ограниченный»/расписание — как попросит пользователь.
7. Финальная сверка всех полей у всех видео канала (`yt_audit_all` / пачками `yt_audit.js`) → отчёт
   `python scripts/yt_audit_report.py <YY.MM>/_youtube_аудит_канал` → таблицу пользователю. Что менять — заранее
   показать и дождаться ОК. Проверка описаний на правила YouTube — тоже по всем видео канала.
   - Если вкладка Studio фоновая — паузы только через приёмник (`/sleep`), иначе Chrome тормозит таймеры.
   - Цикл через iframe иногда вешает вкладку — тогда снимать пачками: navigate + `yt_audit.js` (12 видео за вызов).

## Порядок заливки
На канале шортсы стоят группами по географии (новые сверху). Заливать в обратном порядке — первым
то, что должно оказаться внизу: Херсон → Запорожская область → Запорожье → Запорожье/Восток → … → Сумы →
Харьков → Волчанск → Купянск → Новопавловка → Покровск → Константиновка → Славянск/Лиман → Донецк/Луганск.
Точный порядок сессии — в таблице, согласованной с пользователем.

## Как заливать (проверено в сессии 26.10)
1. План: `<YY.MM>/_youtube_план.json` — n (порядок), file, title, src (прошлый шортс-источник), same (та же карта
   была на канале → копируем всё, включая описание), tags (для новых: город по-русски и по-английски).
   Таблица для пользователя — `<YY.MM>/_youtube_названия.md`; показать и дождаться ОК.
2. Копии для заливки: `python scripts/maps.py upload-prep <YY.MM>` → `<YY.MM>/_upload/` (ширина 1080, < 9.5 МБ —
   браузерный загрузчик берёт < 10 МБ). Широкое (w > h) видео сразу пересобрать в квадрат 1080×1080 с чёрными полями:
   `ffmpeg -i in.mp4 -vf "scale=1080:-2,pad=1080:1080:(ow-iw)/2:(oh-ih)/2:black" …` — квадрат Shorts принимает.
3. Каждое видео: открыть `…/videos/upload?d=ud`, `find` файловый input → `file_upload` из `_upload`,
   вставить `scripts/yt_fill.js` и вызвать `await ytFill(<запись плана>)`. Функция импортирует сведения из прошлого
   шортса («Импортировать сведения»), ставит название, «не для детей», теги, «Ограниченный доступ» и сохраняет,
   ТОЛЬКО если всё сошлось; иначе возвращает сводку — поправить руками (часто: импорт применился с задержкой).
4. Проверить: все в разделе Shorts, во вкладке «Видео» нет ни одного (иначе — пересобрать под квадрат/вертикаль).
5. Расписание (если пользователь просит): страница видео → «Изменить параметры доступа к видео» → раскрыть
   «Запланировать публикацию» → `#datepicker-trigger` → ввод даты в поле календаря и времени **реальным набором**
   (computer type + Return; программно не принимает), «ОК», «Сохранить» → статус «Отложенная публикация».
   В сессии 26.10: раз в 3 ч в порядке заливки (первое — ниже на канале), дата формата «21 окт. 2026 г.».
6. Видео по теме: после заливки всех, в порядке №1 → №37 (чтобы переименованный шортс уже стоял под новым
   названием), страница `studio.youtube.com/video/<id>/edit` → вставить `scripts/yt_fix.js` →
   `await ytFix({rel: '<полное название предыдущего шортса>'})`. Тем же `ytFix` правятся название (`title`)
   и опечатки в описании (`reps: [['было','стало']]` — меняются ВСЕ вхождения, поэтому «было» задавать целым словом
   с контекстом, не «Сум», а «в Суммах»). Возвращает `ok` — только если поле реально встало и сервер ответил на «Сохранить».
7. **Сверка перед словом «готово» — ВСЕ поля страницы, у ВСЕХ видео и шортсов канала, а не по памяти.**
   `python scripts/receiver.py`, в Studio загрузить `yt_audit.js` и `yt_audit_all.js` (через fetch с приёмника
   и `<script nonce>` — eval на Studio запрещён), запустить `ytAuditAll('<YY.MM>/_youtube_аудит_канал')`, не ждать;
   прогресс — `ytAuditAllState`. Снимки — по одному JSON на видео: все разделы, переключатели, галочки, списки,
   доступ, «Видео по теме». Сравнить с шортсами прошлого сезона, пустые/несовпадающие поля — таблицей пользователю.
   **Что и где собираюсь менять — показать заранее и дождаться ОК.** После правок — снять заново (с перезагрузкой
   страниц) и только тогда отчитываться. Не писать «всё заполнено», если хоть одно поле не проверено.
   - Сохранение: после «Сохранить» ждать ответа `video_manager/metadata_update` (так делает `ytFix`, поле
     `saveStatus` = 200). Уйти со страницы раньше = правка теряется (в 26.10 так потерялись 30 из 37).
8. `python scripts/maps.py number <YY.MM>` — префикс номера из плана: папки `+NN_<Имя>_<даты>`, видео `NN_<Имя>_<даты>.mp4`.
9. Удалить `<YY.MM>/_upload`.

## Описания
- Описания пишет пользователь; правки — только по его просьбе (опечатки корректора) или если текст нарушает
  правила YouTube. Город — **Сумы** (одна «м»: Сумы, Сум, Сумах), не «Суммы»; «вялотекущий» — слитно.
- Правила YouTube: без мата и вульгарностей, сексуальных намёков, расчеловечивания («мясо», «орды», «трупами»)
  и обобщений про народ («русские такие-то»). Переписывать только эту фразу, смысл сохранять, остальное не трогать.
- Копия всех описаний канала до правок — `<YY.MM>/_youtube_описания_канала.json` (через receiver.py: POST /save).

## После заливки
- Дождаться проверки. Если видео не стало Shorts (слишком широкое) — пересобрать под вертикальный/квадратный
  формат ffmpeg (поля сверху/снизу до 9:16 или 1:1), удалить/заменить и залить заново.
- Shorts: до 3 минут, соотношение сторон квадрат или вертикаль.
