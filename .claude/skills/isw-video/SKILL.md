---
name: isw-video
description: Сборка видео из нормализованных карт ISW — кадр раз в неделю, 2 секунды на карту, плавный переход через ffmpeg xfade. Использовать после нормализации.
---

`<YY.MM>` = папка сессии (напр. `26.10`): все карты сессии, весь её диапазон дат.

# Видео

> С пользователем — только на русском: ответы, вопросы, кнопки, окошко итога, отчёты.

Требуется ffmpeg в PATH (`winget install Gyan.FFmpeg`, затем новый терминал).

1. Выборка: `python scripts/maps.py pick <YY.MM> [<Папка> ...] [--step 7]`
   - первый доступный день папки берётся всегда;
   - следующая цель = взятый день + 7; если такого дня нет — ближайший доступный **после** цели;
   - так длинные пропуски (направление пропадало на месяц) не ломают ряд;
   - **последний день папки всегда финальный кадр**, даже вне недельного шага.
   Показать пользователю выбранные дни по каждой папке.
2. Видео: `python scripts/maps.py video <YY.MM> [<Папка> ...] [--step 7 --hold 2 --fade 0.3 --fps 30]`
   - вход `_norm/<Папка>/`, выход **`<YY.MM>/<Папка>.mp4`** — то же имя, что у папки, включая диапазон дат
     `_<первый кадр>-<последний кадр>` (напр. `Borova-Tactical-Area_26.01.11-26.10.10.mp4`), на уровень выше картинок;
     прежнее видео этого направления заменяется
     (все видео сессии лежат вместе в папке сессии), включая папки `_old_`;
   - перед видео: `maps.py normalize <YY.MM> <Папка>` (можно по одной папке, которую пользователь одобрил);
   - на каждую карту — `hold` секунд, между картами плавный crossfade длиной `fade` (переход съедает часть показа:
     средние карты видны целиком `hold − fade`, первая и последняя — `hold`); длина видео = кадров × `hold` + `fade`;
   - `video` не собирает, если `_norm` не совпадает с папкой (после `normalize` убрали день) — перезапустить `normalize`;
     длиннее 179 с — `!!` (это уже не Shorts); старое видео заменяется только после удачной сборки;
   - H.264, yuv420p, crf 18.
3. После сборки `video` оставляет в папке только кадры видео и сам вызывает `cleanup`: удаляет навсегда
   `_norm` папки, а когда все папки направления с «+» — ещё `_removed/<направление>` и в `_raw` всё, кроме
   оригиналов кадров видео (пока `_old`/другая часть разбирается, её `_removed` и `_raw` не трогаются). Вручную: `python scripts/maps.py cleanup <YY.MM> [<Папка>]` (заодно удаляет `_skipped`
   и `_raw`/`_removed` направлений, убранных целиком — это же делает `prune`).
   `prune` папки с «+» не трогает.
4. Пометка:
   **Папка, из которой сделано видео, получает «+» в начале имени** (`+Kherson_26.01.02-26.10.13`); `maps.py video`
  ставит его сам. Видео — без «+». В командах папку можно называть без «+» и без дат. После `split` «+» снимается.
5. Последнее видео сессии (все папки с «+») → `video` сам делает `handoff`: по одной последней карте каждого
   направления (с оригиналом) переезжает в папку следующей сессии — отправная точка. Вручную: `maps.py handoff <YY.MM>`.
   Направления, которые в следующей сессии уже есть, повторно не переносятся (пересборка видео закрытой сессии
   не забирает ещё кадр).
6. Готовые видео в чат НЕ отправлять (просьба пользователя) — только написать имя файла и число кадров.
