# ISW maps → видео

Проект собирает карты боевых действий **Россия–Украина** с сайта Institute for the Study of War
(https://understandingwar.org) и делает из них видео-таймлапсы по каждому направлению.

Источник — ежедневные статьи **«Russian Offensive Campaign Assessment, <Month> <D>, <YYYY>»**.
В каждой статье несколько карт: общая карта войны и карты направлений
(Kostyantynivka, Vovchansk, Kherson, Zaporizhia, …). Название направления и дата видны в синей
шапке карты: `Assessed Control of Terrain in the <Направление> Direction / <Month D, YYYY> at …`.
Другие темы ISW (Иран, Китай и т.д.) не берём.

## Сессии

Пользователь приходит **раз в квартал**. Каждый приход — одна **сессия** со своей папкой `<YY.MM>` =
квартал даты прихода по первому месяцу (пришёл в октябре 2026 → `26.10`; в январе 2027 → `27.01`).
Сессия собирает карты **со дня после последнего собранного** (по всем прошлым сессиям) **по сегодня**;
первая сессия `26.10` — с 1 января 2026. Весь диапазон дат сессии лежит **в одной её папке** —
папки НЕ делятся по кварталам дат карт. Вся работа сессии (сбор, обрезка, проверка, видео) — только внутри её папки.
`python scripts/maps.py next` — папка текущей сессии и с какого дня собирать.

**Отправная точка.** Когда в сессии сделано последнее видео (все папки с «+»), по одной последней карте каждого
направления (и её оригинал из `_raw`) переносится в папку следующей сессии (`26.10` → `27.01`): там уже лежат
папки `<Имя>_<дата>-<дата>` с этой картой. Новая сессия докладывает новые карты в эти же папки, и видео
начинается с последнего кадра прошлой сессии. `video` делает это сам; вручную — `maps.py handoff <YY.MM>`.
`prune` в новой сессии запускать только после сбора и обрезки новых карт (иначе снесёт папки с 1 картой).

## Что делаем в сессии

1. **Сбор** — все дни со дня после последнего собранного по сегодня, все карты-оригиналы. → скил `isw-collect`
2. **Обрезка** — срезать легенду под картой (с 2026 года), чтобы её разная высота не меняла формат.
   Мини-карта и подписи авторов поверх карты остаются. → скил `isw-process`
3. **Водяной знак** — `FRIST_008` чёрным, прозрачность 75% (малозаметный), справа вверху у строки с датой, на каждой карте. → `isw-process`
4. **Проверка с пользователем** — по каждой папке отдельно спросить: всё ли там правильно лежит и одна ли это карта.
   Делается после обрезки, но **до** уменьшения. Карта может смениться при том же названии направления. → скил `isw-review`
5. **Нормализация** — внутри папки все карты одного соотношения сторон; большие (4K) уменьшаем до размера маленьких (HD). → `isw-process`
6. **Видео** — по каждой папке (включая `_old_`): кадр раз в 7 дней (или реже), каждая карта 2 с, плавный переход. → скил `isw-video`
7. **YouTube** — когда все видео готовы: залить как Shorts на канал «Карты: Россия Против Украины с 2022года»
   (ограниченный доступ, метаданные как у прошлых шортсов, расписание — если попросят), пронумеровать. → скил `isw-youtube`

## Структура файлов

```
<YY.MM>/                         папка сессии (квартал прихода): 26.10 — даты 2026-01-01 … 2026-10-18
  _manifest/<yyyy-mm-dd>.json    какая статья / какой URL картинки / какое направление (по дню)
  _collect/                      статус и пульс сбора (status.json, heartbeat.txt, прошлые прогоны)
  _сводка_по_папкам.txt          папка → число карт, первая и последняя дата
  _raw/<Направление>/<yy.mm.dd>.<ext>   оригиналы с сайта, никогда не меняем
  [+]<Направление>_<первый>-<последний>/<yy.mm.dd>.png   обрезанные карты («+» — видео сделано); в конце имени папки — первая и последняя
                                         даты карт в ней (Borova-Tactical-Area_26.01.11-26.10.10)
  <Направление>_old_<первый>-<последний>/   старая версия карты после разделения
  _removed/<Направление>/               дни, которые пользователь попросил убрать (не удаляем навсегда)
  _norm/<Папка>/                        одного размера, вход для видео (временная, удаляется после видео)
  <Папка>.mp4                    видео — то же имя, что у папки (с датами первого и последнего кадра), на уровень выше картинок:
                                 все видео сессии лежат вместе в папке сессии
scripts/receiver.py              локальный приёмник: браузер POST-ит сюда скачанные картинки, отдаёт collect.js
scripts/collect.js               сборщик, выполняется во вкладке understandingwar.org
scripts/croplib.py               поиск рамки легенды и обрезка по ней
scripts/maps.py                  next / crop / mark / check / sheet / split / remove / merge / ranges / prune /
                                 normalize / pick / video / cleanup / handoff
PLAN.md                          поэтапный план и журнал прогресса — читать в начале каждой сессии
```

## Имена папок и видео

Не как у ISW, а по шаблону — чтобы одни и те же города стояли рядом при сортировке:

`Город[-Oblast|-City|-River][-North|-South|-East|-West|-NorthEast…][-Город2][-Zoom|-Zoomed-Out]`

- первым — город (или область), тип `-Oblast`/`-City`/`-River` **сохраняем**; сторона света — после него;
  второй город — если карта про два города; масштабная пометка — в самом конце.
- «Tactical-Area», «Direction», «Agglomeration» отбрасываем; Запорожье — всегда `Zaporizhzhia`.
- не город: `Overview` (общая карта войны) — оставить; пояс городов — по городам (`Fortress-Belt` → `Kramatorsk-Slovyansk`);
  граница — `Border-NorthEast`.
- Таблица «имя ISW → наше имя» — `scripts/names.json`; `crop` создаёт папки уже по ней, `_raw` остаётся под именами ISW.
  Новое имя ISW, которого нет в таблице: придумать по шаблону, **спросить пользователя**, дописать в `names.json`.
- Полное имя папки: `[+][NN_]<Имя>[_old]_<первый день>-<последний день>`, видео — то же без «+».
  `NN_` — номер в порядке заливки на YouTube (`maps.py number` после заливки).
  Имя файла карты — дата из шапки, `yy.mm.dd`.

## Правила

- **С пользователем — только на русском.** Всё, что он видит: ответы, вопросы, кнопки, окошко итога (recap /
  next-step), подписи, отчёты мониторов. Ни слова на английском или другом языке.

- **О направлениях говорить только полным именем папки**, как на диске (`Eastern-Dnipropetrovsk_26.02.27-26.03.10`),
  а не сокращённым названием направления.
- **Даты в сообщениях пользователю — только цифрами**, как в именах файлов: `26.02.27` (или `27.02`), без названий месяцев.

- **Вкладку understandingwar.org в Chrome никогда не закрывать** — она уже прошла проверку Cloudflare «не робот».
  Работать в существующей вкладке ISW, новую не открывать без нужды.

- Сайт закрыт Cloudflare: curl/requests получают 403. Работать через Chrome пользователя (Claude in Chrome);
  во встроенном браузере капча не проходит. Галочку Cloudflare нажимает пользователь — Claude капчи не проходит.
- Оригиналы в `_raw` не менять. Пока направление разбирается, лишнее убирать в `_removed/`, не удалять.
- **После видео — удалять навсегда (просьба пользователя):** `_norm` этих папок, `_removed/<направление>`,
  а в `_raw` оставить только оригиналы кадров видео (если все папки направления уже с «+»). `video` делает это сам
  (`cleanup`). Направление убрано целиком (не осталось ни одной папки) — его `_raw` и `_removed` удаляются
  сразу (`prune`/`cleanup`). `_skipped` не хранить — удалять сразу (сборщик тематические карты и не качает).
- После видео в папке остаются только её кадры (раз в 7 дней), остальное удаляется (см. выше).
- **«+» в начале имени папки = видео из неё уже сделано** (`+Donetsk-Oblast_26.01.10-26.07.18`). `video` ставит его
  сам; видео называется без «+». После `split` обе части теряют «+» (видео надо делать заново).
- Имена папок направлений и видео всегда заканчиваются диапазоном `_<первый>-<последний>` (`yy.mm.dd`).
  split/remove/merge сами переименовывают папки; вручную — `python scripts/maps.py ranges <YY.MM>`.
  В командах папку можно называть без диапазона (`Kherson`). Оригиналы в `_raw/<Направление>` — без диапазона.
- Разделение папки по дате: `python scripts/maps.py split <YY.MM> <Папка> <yy.mm.dd>` — дни раньше даты
  уезжают в `<Папка>_old_<первый>-<последний>`, новые остаются в `<Папка>_<первый>-<последний>`.
- **В папке минимум 3 карты и охват от первой до последней даты минимум 15 дней.** Иначе папке не место среди
  направлений: `python scripts/maps.py prune <YY.MM>` уносит такие в `_removed` (запускать после обрезки и после
  любых правок папок). `video` такие папки не собирает.
- Видео: последний день папки всегда финальный кадр (даты в имени видео = первый и последний кадр).
- Перед видео каждая папка должна пройти проверку пользователя (шаг 3). Не пропускать.
- **Не писать «готово/всё заполнено», не проверив каждое поле каждого видео** (для YouTube — сверка через API Studio,
  см. `isw-youtube`). Описания: опечатки корректора и нарушения правил YouTube правлю сам, не спрашивая как.
- Заметки о проекте хранить только в папке проекта (CLAUDE.md, PLAN.md, скилы), не в памяти профиля Claude.
- Работаем медленно по `PLAN.md`: после каждого этапа показать результат и дождаться ОК.
- Инструменты: Python 3.12 + Pillow (есть), ffmpeg (нужен для видео).
